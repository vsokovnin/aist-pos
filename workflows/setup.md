# Настройка — ленивая, по потребности

Установочной церемонии нет. Поток вызывается в двух случаях: на первом запуске (минимальный конфиг) и в момент, когда конкретному сценарию не хватает файла.

## Первый запуск — только минимум

Признак: рядом нет `aist-pos.config.yaml`.

1. Спроси **два** вопроса: как к вам обращаться и часовой пояс. Больше ничего.
2. Скопируй `config/aist-pos.config.example.yaml` в рабочую папку человека как `aist-pos.config.yaml`, подставь ответы, остальные источники оставь `none`.
3. Скажи одной строкой, что настройка закончена, и веди в оценку (`workflows/assess.md`).

Не спрашивай на входе про почту, календарь, мессенджер и транскрипты. Оценка их не требует, а подключения предлагаются позже — когда человек выберет направление, которому они нужны.

## Донастройка — в момент нужды

Сценарий упёрся в отсутствующий файл — заведи ровно его, объясни одной фразой зачем, и продолжи прерванную работу. Не создавай «заодно» остальное.

| Чего не хватает | Из чего создать |
|---|---|
| памятка для агента (`CLAUDE.md` или `AGENTS.md`) | `templates/root-file.template.md`, подставь имя, роль, часовой пояс |
| правило имён файлов | `templates/naming-convention.md` |
| список «что где лежит» | `templates/source-map.template.md` |
| файл памяти агента | `templates/memory.template.md` |
| история изменений | `templates/gitignore.template`, затем `git init` и подсказка про копию вне компьютера |
| карточки людей, организаций, проектов | папки `entities/{org,person,project}/`, схема — `config/entities-schema.md` |
| папка результатов | `runtime/` |

## Подключения — проверка по запросу

Когда человек спрашивает «что у меня подключено» или выбирает направление, которому нужен внешний источник:

- определи фактическую доступность в среде: в Claude Code — соответствующий MCP по `config/connectors.md`, в Cowork — подключённый коннектор;
- статус по каждому: подключён · заявлен, но не авторизован · не используется;
- предложи **одно** подключение за раз, с объяснением, какой сценарий оно открывает. Ссылки и рекомендации — `docs/recommended-setup.md`.

Подключить за человека нельзя: авторизация — интерактивный шаг. Навык только проверяет и ведёт.

## Правила

- Идемпотентность: существующие файлы не перезаписывать, предлагать слияние или пропуск.
- Ничего наружу; только рабочая папка человека.
- Портативность: ни одной ссылки на чужую инфраструктуру, всё из шаблонов и конфига навыка.
- Не заводить впрок: файл, которым никто не пользуется, считается незанятой основой, а не зрелостью.
