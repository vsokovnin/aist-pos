# Маршрутизация — только когда конфиг уже есть

Этот файл читается после проверки первого запуска в `SKILL.md`. Нет `aist-pos.config.yaml` — сюда не заходят: первый запуск всегда идёт в оценку.

Определи, что человек просит, и открой ОДИН файл потока. Не читай остальные.

| Человек говорит | Поток |
|---|---|
| «оцени», «насколько зрело», «с чего начать», повторная оценка | `workflows/assess.md` |
| «покажи страницу», «обнови план», сразу после оценки | `workflows/page.md` |
| «что у меня сегодня», «утренний бриф» | `workflows/brief.md` |
| «разбери переписку», «что я должен», «кто мне должен» | `workflows/tasks.md` |
| «подготовь к встрече с X» | `workflows/meeting-prep.md` |
| «оспорь мою позицию», «поспорь со мной», «найди слабые места», «что скажут на совете» | `workflows/challenge.md` |
| «поставь в календарь», «забронируй время» | `workflows/schedule.md` |
| «запомни этих людей», «обнови карточки» | `workflows/entities.md` |
| «настрой», «донастрой», не хватает файла для сценария | `workflows/setup.md` |

Маршрут выбираешь ты по тому, что человек сказал, — не он из списка. Никогда не показывай ему эту таблицу и не спрашивай, какой сценарий запустить.

Непонятно, чего человек хочет, — задай один уточняющий вопрос своими словами, без перечисления возможностей.
