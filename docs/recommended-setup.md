# Что подключать и в каком порядке

Подключения — интерактивный шаг: авторизацию проходит человек сам, навык только показывает, что доступно, и ведёт. Полная карта значений — `config/connectors.md`.

**Главное правило: до первой пользы не подключается ничего.** Оценка работает на файлах и вопросах, страница — локальный файл. Первое подключение предлагается тогда, когда человек выбрал задачу, которой оно нужно.

## Что нужно каким задачам

| Задача | Что понадобится |
|---|---|
| День начинается с одной сводки | почта и календарь |
| К встрече готов за пять минут | почта и календарь |
| Ничего не забыто | почта, по желанию мессенджер |
| Отчёт за двадцать минут · К совету | ничего: документы кладутся в папку |
| Обзор рынка · Досье за десять минут | внешний поиск |
| Черновик ответа · Итоги встречи · Слайды · Квартал · Ассистент | ничего |

Половина задач не требует ни одной авторизации. Это не случайность, а осознанный выбор: человек должен получить результат раньше, чем его попросят куда-то войти.

## Базовый набор для России

**Яндекс 360 для бизнеса** — рекомендованный дефолт, если почта и календарь на российской инфраструктуре. Почта по OAuth, календарь по CalDAV с правом записи, диск. Организация выдаёт доступ через сервисные приложения в админке.

**Google Workspace** — дефолт, если человек живёт в Google. Доступен по личному OAuth на всех планах и уверенно пишет в календарь.

**Microsoft 365** — только внутри корпоративного арендатора, с правами администратора и **на чтение**: события в календарь придётся ставить руками.

**Mail.ru и VK WorkSpace** — если почта там; в экосистеме заодно календарь, диск и звонки.

## Встречи и расшифровки

Если встречи проходят в российских сервисах, расшифровка достаётся программно, а не переписыванием от руки:

- **Контур.Толк** — транскрипция, резюме и протокол встречи, есть локальная установка;
- **SberJazz** — отдельный метод для получения расшифровки по спикерам;
- **Яндекс Телемост** — конференции создаются и читаются через API;
- свои записи — расшифровываются отдельно, например через Яндекс SpeechKit.

Granola и Plaud тоже поддержаны, но это иностранные сервисы: для многих российских компаний они недоступны или неприемлемы.

## Мессенджеры

Telegram, MAX, Пачка, VK WorkSpace, eXpress. У MAX Bot API почти совпадает с телеграмным, у Пачки есть готовые библиотеки, eXpress ставится в закрытом контуре — выбирайте по тому, где реально идёт рабочая переписка.

## Прежде чем строить интеграцию

Проверьте, нет ли готового MCP-сервера. У Битрикс24 с июля 2026 есть собственный, у Яндекс Трекера — сделанный сообществом. Там, где такой сервер уже существует, писать коннектор не нужно вовсе.

*Каталог сервисов и их условия меняются быстро — сверяйтесь с актуальной документацией самих сервисов.*
