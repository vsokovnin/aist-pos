# Персональный сайт-визитка через Claude Code

**Сайт, который собирает и публикует ваш Claude Code, а вы решаете, что на нём написано и как он выглядит.**

## Что получится

Одностраничный сайт на вашем домене. Весь сайт — три файла, без панели администратора и базы данных. Правки вносятся не в код, а разговором: вы говорите, что изменить, агент переписывает.

## Что понадобится

- Установленный Claude Code — [инструкция по установке](https://code.claude.com/docs/en/quickstart).
- Домен — свой или купите по ходу.
- Хостинг — порядка 250 руб. в месяц.
- Около двух часов вашего времени. Ожидание сверх того и от вас не зависит: ответ поддержки хостинга приходит в течение дня, настройки домена расходятся по интернету до суток. Планируйте не «к обеду», а «за пару дней».

## Три шага, два файла инструкции

1. Собрать сайт у себя и посмотреть, что получилось — файл `01-build-site.md`.
2. Довести до состояния «нравится» — тот же файл.
3. Опубликовать на домене — файл `02-publish.md`.

## Как запустить

Оба файла гайда — `01-build-site.md` и `02-publish.md` — лежат в этой же папке, рядом с этим README.

**Как их скачать.** Откройте страницу файла на GitHub, нажмите кнопку «Raw» над текстом — откроется чистый текст, — и сохраните страницу браузером: `Ctrl+S` на Windows, `Cmd+S` на macOS. Не нашли кнопку или проще взять всё сразу — на главной странице проекта зелёная кнопка «Code», в ней «Download ZIP»; распакуйте архив и возьмите оба файла из папки `guides/personal-site`.

Дальше перетащите `01-build-site.md` в окно Claude Code и напишите:

«Прочитай этот файл и начни с этапа 1. Веди меня по порядку, по одному шагу за раз».

Скачанный файл не удаляйте: если Claude Code придётся перезапустить, его нужно будет перетащить заново.

Когда дойдёте до публикации — так же скачайте и перетащите `02-publish.md`.

Сами файлы `01-build-site.md` и `02-publish.md` написаны агенту, а не вам: это инструкция о том, как ему себя вести и о чём вас спрашивать. Читать их необязательно — если откроете из любопытства, не удивляйтесь, что там про вас говорят в третьем лице.

## Чего этот гайд не делает

- Не учит устанавливать Claude Code — для этого ссылка выше.
- Подробно ведёт только по хостингу Timeweb; для остальных хостингов — чеклист, дальше сами.
- Не делает интернет-магазин, блог или формы обратной связи.

## Если застряли

Шаг не проходится, агент упёрся, в самой инструкции ошибка или чего-то не хватает — напишите об этом в issues проекта: [github.com/vsokovnin/aist-pos/issues](https://github.com/vsokovnin/aist-pos/issues). Скажите, на каком шаге встали и что видите на экране. Туда же — замечания к гайду: он живой и правится по таким сообщениям.

Насколько зрелы ваши процессы — показывает оценка: навык AIST POS лежит в корне этого проекта на GitHub — [github.com/vsokovnin/aist-pos](https://github.com/vsokovnin/aist-pos).
