# Персональный сайт-визитка через Claude Code

**Сайт, который собирает и публикует ваш Claude Code, а вы решаете, что на нём написано и как он выглядит.**

## Что получится

Одностраничный сайт на вашем домене. Весь сайт — три файла, без панели администратора и базы данных. Правки вносятся не в код, а разговором: вы говорите, что изменить, агент переписывает.

## Что понадобится

- Установленный Claude Code — [инструкция по установке](https://code.claude.com/docs/en/setup).
- Домен — свой или купите по ходу.
- Хостинг — порядка 250 руб. в месяц.
- Около двух часов времени.

## Три шага

1. Собрать сайт у себя и посмотреть, что получилось.
2. Довести до состояния «нравится».
3. Опубликовать на домене.

## Как запустить

Скачайте файл `01-build-site.md`, перетащите его в окно Claude Code и напишите:

«Прочитай этот файл и начни с этапа 1. Веди меня по порядку, по одному шагу за раз».

Когда дойдёте до публикации — так же перетащите `02-publish.md`.

## Чего этот гайд не делает

- Не учит устанавливать Claude Code — для этого ссылка выше.
- Подробно ведёт только по хостингу Timeweb; для остальных хостингов — чеклист, дальше сами.
- Не делает интернет-магазин, блог или формы обратной связи.

## Что дальше

Сайт — самое простое, что агент делает за вас. Тот же агент разбирает вашу переписку в задачи и обязательства, готовит вас к встречам, помнит ваш контекст и базу контактов. Насколько зрелы ваши процессы — показывает оценка: навык AIST POS лежит в корне этого репозитория.
